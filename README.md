# Deep Learning Architecture Practice Lab 🧠

A hands-on deep learning practice repository focused on implementing, training, evaluating, and deploying different neural network architectures using **TensorFlow and Keras**.

This project explores the progression from traditional feed-forward neural networks to modern sequence-based architectures, including:

- Dense Neural Networks
- GRU, RNN & LSTM Networks
- Attention Mechanisms
- Transformer Blocks
- Hybrid Deep Learning Models
- FeedForward Neural Network

The goal is to understand how different architectures learn patterns from data and when each model is most suitable.

### 📌 Project Overview

This repository serves as a deep learning experimentation environment where different neural network architectures are built and tested on synthetic and real-world style datasets.

The project includes:

- Model development using TensorFlow/Keras
- Custom model utilities
- Model saving and loading
- Prediction pipelines
- Hybrid architecture experiments
- Deployment simulation
- Architecture testing
